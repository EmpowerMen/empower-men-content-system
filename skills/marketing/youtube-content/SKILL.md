## youtube-content

## Description  
Create compelling YouTube video thumbnail headlines, video titles, and video descriptions optimized for the EmpowerMen channel focused on the King Warrior Magician Lover (KWML) framework and men's personal development.

## Triggers  
- write youtube title  
- create thumbnail headline  
- draft video description

## Inputs  
- Video topic (e.g., "Magician Archetype: Harnessing Intuition")  
- Target audience (e.g., "men interested in masculine psychology and personal growth")  
- Key message or value proposition (e.g., "how to develop intuition for personal growth")  
- SEO keywords (e.g., "KWML framework, Magician archetype, masculine intuition")  
- Video length (optional)  
- Call to action (optional, e.g., "Subscribe for more KWML insights")

## Workflow  
1. Analyze the video topic and key message.  
2. Draft a punchy, concise thumbnail headline (5-7 words) that hooks the viewer.  
3. Write an SEO-optimized video title (50-60 characters) front-loading important keywords.  
4. Create a video description that:  
   - Hooks the viewer in the first 150 characters.  
   - Summarizes the video content clearly.  
   - Includes timestamps if applicable.  
   - Adds relevant links (e.g., channel, website).  
   - Includes calls to action (subscribe, comment).  
   - Uses relevant hashtags and keywords naturally.

## Degrees of Freedom  
- Tone: educational, motivational, authoritative, approachable  
- Keyword density: moderate, natural  
- Emoji usage: minimal, appropriate for audience  
- Length flexibility for description based on video length
